## Firescale Studios S.L. | March - May 2025

35-day internship as a systems programmer on an unannounced game, working with <mark>Unity</mark> and <mark>C#</mark>.

# Role

I worked as a <mark>systems programmer</mark> on a 6-person core team, on-site four days a week.

I was brought on to implement gameplay systems but the project structure wouldn't allow me to implement automated tests on these systems.

# About the Project

The project inherited a <mark>Game as a Service</mark> (GaaS) architecture, with engine and client code tangled together in one codebase.
The Object System<mark>\*</mark> no longer worked outside its original context.

<mark>\*</mark>The project uses another term, which I substitute for _*Objekt*_ to respect the signed NDA.

## What I Did

- Decoupled the `Objekt` class from Unity with `IObjektData` interfaces, so the engine reads data without knowing where it came from.
- Split the code into assembly definitions for engine, client and dev tools.
Tests could not run without this.
- Replaced hardcoded elements teammates had added with the new data structures.

## Outcomes

After my work, the core "backend" of the project was decoupled.
I separated engine and client code, and cut duplication.
The team could run unit tests going forward.

This internship fulfilled the external practicum (_VJ1240 - External Work Placement_) for the [Video Game Design and Development](https://www.uji.es/estudis/base/2023/graus/videojocs/) degree at [Universitat Jaume I](https://www.uji.es/).
